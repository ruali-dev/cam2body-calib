# Coding preferences

- Prefer simple, maintainable code over clever abstractions.
- Keep changes minimal and localized unless refactoring is explicitly requested.
- After editing code, run the narrowest available syntax/type/test/build check.
- Do not claim the code is correct unless a check was run or explain why no check could be run.
- For C++, prefer C++17 unless the project specifies otherwise.
- For Python, prefer type hints for public functions and avoid unnecessary heavy dependencies.
- For scripts and prototypes, prioritize fast iteration, clear errors, and easy debugging.
